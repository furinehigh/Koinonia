# Installation
1. Clone the repo, i'm sure u know how to achieve this, r? or maybe not so...
```bash
git clone https://github.com/furinehigh/Koinonia.git
cd Koinonia
```
2. Rename the `.env.example` file to `.env` and put all the required variable there such as Github OAuth client and secret..

3. Install node modules
```bash
npm i
```
4. Run the app in development
```bash
npm run dev
```

Now u can easily visit `http://localhost:3000` to get the result.
