# Koinonia-WS
Node.js server for websocket. Should be deployed seperately.

# Installation
- Create a `.env` file with `REDIS_URL` and `PORT` variables. Check out the `.env.example` file.
- Build and start the server:
```bash
npm run build
npm run start
```
- Your WS server is now successfully working on your desired port, now you should put the URL or IP with port in your Koinonia frontend.
